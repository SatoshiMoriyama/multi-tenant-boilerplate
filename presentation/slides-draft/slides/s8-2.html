Aurora Serverless v2 ── 行レベルセキュリティ（RLS）

  • 強整合・結合・トランザクションが要るなら RDB。Silo / Bridge / Pool の 3 モデルに対応
  • Pool では論理分離が無いので RLS 必須: PostgreSQL の CREATE POLICY ＋ セッション変数 current_setting('app.tenant_id') で行を自動フィルタ
  • 多数テナントは接続数が膨らむ → RDS Proxy で接続プールを束ねる
Silo = テナントごとに DB インスタンス、Bridge = 1インスタンス内で DB / スキーマ、Pool = 単一 DB / スキーマ ＋ RLS。 接続のたびにテナントコンテキストをセットする。RDS Proxy が補助の定石。
