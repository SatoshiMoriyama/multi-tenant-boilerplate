Verified Permissions ── アプリ層の認可（任意）

IAM ＝ リソース層の境界 ／ Verified Permissions ＝ アプリ層の認可（マネージド PDP）

Cedar で「テナント A のユーザーはテナント B のドキュメントを閲覧不可」を宣言的に記述

まとめ

Cognito（発生） → IAM ABAC（リソース縛り） → Verified Permissions（アプリ認可）
を tenantId が貫通

IAM がリソース層なら Verified Permissions はアプリ層の認可。マネージドな PDP。 Cedar ポリシー言語でテナント条件を含む粒度の細かい判定。物理的に同居していても論理的に不可を宣言できる。 「このユーザーはこの操作をこのリソースにできるか」を外部化したいときの選択肢。今日は紹介に留める。 章まとめ: tenantId が Cognito → IAM → Verified Permissions の3サービスを貫通する。
